# Weight Predictor Model & App

1. Clone the repository on your pc or download the zip folder and extract the Android project
2. Open the weight predicter app in android studio and let the gradle sync
3. Run hte project on a emulator or through your androiod phone
4. Once the app is istalled and open, you willl see a page that will prompt you for a height of your choosing
5. Once you typed a height (in cm), and click the button Predict, the predicted weight will display in a message below the button
